# Portfolio notes

## Repository name
`pulsechat-realtime-websocket`

## GitHub description
Full-stack real-time chat platform built with React, Redux-Saga, Node.js, WebSockets, PostgreSQL and TypeScript.

## Resume bullets
- Built a full-stack real-time chat platform with React, TypeScript, Redux Toolkit, Redux-Saga and native WebSockets.
- Designed a Node.js WebSocket gateway with room broadcasting, presence and persistent messaging.
- Added JWT authentication, bcrypt password hashing, PostgreSQL/Prisma persistence, validation and rate limiting.
- Added Docker Compose and GitHub Actions CI for reproducible development and automated builds/tests.

## Interview topics
Explain WebSockets vs HTTP polling, Redux-Saga side effects, optimistic UI, reconnect logic, JWT, Prisma, PostgreSQL indexing, room broadcasting, and how you would scale the WebSocket layer horizontally.
